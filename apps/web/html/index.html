タスク管理アプリに疲れたあなたへ。 余計な機能はない。誰でも、すぐに使いはじめられる。 それでいて、必要なときは共有もできる。

無料ではじめる

無料で使えます。メールアドレスで登録して、ブラウザですぐに使えます。iPhone / Android アプリは申請準備中です。

Lightlistの3つのこと

これだけでいい

タスクを追加して、完了する。それだけ。説明書もチュートリアルも必要ありません。はじめてでも迷わない、ちょうどいいシンプルさです。

どこからでも、そのまま使える

パソコンでもスマートフォンでも、ブラウザからそのまま使えます。どのデバイスからでも同じリストをリアルタイムに確認・編集できます。iPhone / Android アプリは現在、申請準備中です。

必要なとき、共有できる

共有コードを発行するだけで、家族・友人・チームとリアルタイム共有。一人で使うだけでも、もちろん十分です。

そのほかの機能

毎日使うのに必要な機能をそろえています。

カレンダー

すべてのリストのタスクを、月カレンダーでまとめて確認できます。日付を選んでタスクを追加することもできます。

日付の入力

「明日 牛乳を買う」「12/24 プレゼント」のように入力すると、日付つきのタスクになります。

ピン留めと並び替え

ピン留めしたタスクは先頭に表示されます。日付順の自動並び替えと、ドラッグでの並び替えができます。

入力候補

一度入力したタスクは候補として表示されるので、よく使うタスクをすばやく追加できます。

オフライン対応

オフラインでもタスクの追加・完了・編集ができます。変更はオンラインに戻ると自動で同期されます。

色とテーマ

リストごとに背景色を選べます。ライト / ダークテーマに対応しています。

多言語対応

画面の表示を 11 の言語から選べます（日本語、英語、スペイン語、ドイツ語、フランス語、韓国語、中国語（簡体字）、ヒンディー語、アラビア語、ポルトガル語、インドネシア語）。日付の入力も各言語の表現に対応しています。

使い方の例

買い物リスト

家族で共有して、買ったものにチェックを付けられます。追加した内容はすぐに全員に反映されます。

家族のやること

ゴミ出しや支払いなどに日付を付けておくと、カレンダーで予定を確認できます。

旅行の準備

持ち物や予約のリストを、一緒に行く人と共有できます。

小さなチームのタスク

共有コードを送るだけで使いはじめられます。少人数でのタスク共有に向いています。

よくある質問

無料で使えますか？

はい、無料です。メールアドレスとパスワードで登録するだけで、すべての機能を使えます。

リストを共有するには？

リストの共有ボタンから共有コードを発行し、URL を相手に送ります。相手はログインなしで内容を確認でき、ログインしてリストに参加すれば一緒に編集できます。

どの端末で使えますか？

パソコンやスマートフォンのブラウザで使えます。同じアカウントでログインすれば、リストは自動で同期されます。iPhone / Android アプリは現在、ストアへの申請準備中です。

アカウントやデータは削除できますか？

設定画面からいつでもアカウントを削除できます。削除すると、タスクリストなどのデータもあわせて削除されます。
